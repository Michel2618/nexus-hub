# 🏡 nexus-hub

This repository contains a collection of custom DIY smart home automation projects and IoT modules. While each module can operate independently, they are designed with future interconnection in mind.

## Repository Structure

Each hardware node has its own directory containing the source code, wiring details, and specific setup instructions.

| Module | Status | Description |
| :--- | :--- | :--- |
| **[Smart Gate Bell](./Smart-Gate-Bell)** | Active | ESP-based smart doorbell that triggers a physical relay and sends Telegram notifications. |


## General Requirements
*   Microcontrollers (ESP8266 / ESP32 variants)
*   Arduino IDE or PlatformIO
*   2.4GHz Wi-Fi Network

Navigate to the individual project folders for specific hardware requirements and deployment instructions.
